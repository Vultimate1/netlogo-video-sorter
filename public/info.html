What is Emergent Behavior?
Description
Definition: A key concept in the study of autonomous robots to enable complex and adaptive behaviors from simple rules and interactions between individual robots
Problem statement:
  • Military tactics require prediction of drone swarm behavior, given the increasing integration of drone swarms in defense and reconnaissance.
  • Swarm algorithms have been modeled off insect behavior, such as ants and bees, and work based off hive mind methodology. While widely recognizable by humans, automating this technology is necessary to increase accuracy and speed in using swarm behavior implementation to predict future behavior of opposite swarms.
  • This requires repeated monitoring of mobile data such as pose, trajectory, center of mass, and boundary-boundary interactions within a swarm, as well as the overall shape of the swarm over time.
  • Making training neural networks more efficient to interpolate emergent behavior of swarms is important for being able to replicate this behavior and achieve savings in cost and time.
Examples
  • Bird flocks: Groups of birds travel together for migration and transportation.
  • Ant colonies: Groups of ants communicate through pheromones to create the shortest path to find food for the colony.
  • Schools of fish: Fish travel in complex coordinated patterns to confuse predators and to get to the nearest source of food.

  • Purpose: Recording drone simulations
  • How it works:

      Features
    • Agent(s): Any moving autonomous object
    • Couzin swarm: A set of autonomous agents that move and interact with each other, forming an overarching behavior after a long period of time
      Procedure
    • Set parameters:
      • Minimum Vision: How many agents can each agent see at a time?
      • Minimum Separation: The minimum proximity between each agent at a given time
      • Maximum Alignment Turn: The maximum angle any agent turns at a given time to align with an adjacent agent
      • Maximum Coherence Turn: The maximum angle any agent turns at a given time to adhere to an overarching pattern or cluster behavior
      • Maximum Separation Turn: The maximum angle any agent turns at a given time to deviate from a cluster
      • Population: The number of agents in the swarm
    • Set recording parameters:
      • Set simulation time (1 - 5 minutes).
      • Enable recording.
    • Start recording!
